# Hara Homebrew tap

Official Homebrew formulas for [Hara](https://github.com/hara-lang/hara).

```shell
brew install hara-lang/tap/hara
brew install hara-lang/tap/hara-truffle
```

- `hara` installs the compact Rust CLI.
- `hara-truffle` installs the Truffle native image.

Both formulas use verified archives published by Hara GitHub Releases. Formula
updates are generated and pushed by the Hara release workflow after its binary
and installer smoke tests pass.
